## 결론 먼저

**최종 모델: v4 단독 + conf 0.25**
- 33장 평가 Top-1 **46.8%** (baseline 29.8% 대비 **+17.0pp**, v2 단독 31.9% 대비 **+14.9pp**)

ensemble은 모두 v4보다 후퇴(-2.1pp~-4.2pp). v4가 충분히 강해 약한 모델이 끌어내리는 패턴이라 단일 모델 추론으로 결정.

## conf threshold sweep

| conf | v4 Top-1 | v4 FP |
|---|---|---|
| 0.05 (default) | 46.8% | 84 |
| 0.10 | 46.8% | 29 |
| 0.20 | 46.8% | 14 |
| **0.25** | **46.8%** | **10** ★ |
| 0.30 | 44.7% | 7 |

conf 0.25에서 Top-1 손해 0, FP 84 → 10으로 88% 감소. 0.30 이상은 Top-1 -2.1pp 손해 발생.

## Hallucination 분포

- v2 91회 → v4 **71회** (-20)
- 합성 다양화(v3)는 분포 재배치만 했지만, augmentation 다양성(v4)은 **양 자체 감소**

## 학습 곡선 분석
