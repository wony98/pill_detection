# data/synthetic/

합성 데이터 생성 노트북. 학습용 합성 이미지를 만드는 절차(v1~v3 진화)와 손바닥 마스크/어두운 배경 변형 생성기.

| 파일 | 내용 |
|---|---|
| `synthetic_images_v2.ipynb` | v2 합성 이미지 생성 (배경 다양화) |
| `synthetic_images_v3.ipynb` | v3 합성 이미지 생성 (palm 마스크 + dark surface 통합) |
| `palm_mask_rembg_colab.ipynb` | rembg로 손바닥 마스크 추출 (Colab) |
| `generate_dark_surface.ipynb` | 어두운 배경 합성 변형 생성 |

진화 배경/근거는 [`docs/합성_진화/합성_v1_v2_v3_진화.md`](../../docs/합성_진화/합성_v1_v2_v3_진화.md) 참조.
