# 합성 통합본 모델 진단 결과

진단 대상: RTMDet-tiny + 합성 통합본 7200/800 학습 (Test Top-1 29.8%)
검증 데이터: Test 33장 / 47 GT / 31 클래스 등장 + 학습 곡선(scalars.json) + K-code 학습 ROI + 합성 분포 + 각인 가시성 측정 + 오탐 박스 정밀 분류

## 결론

**학습/모델 자체는 정상입니다**
- Val mAP@50 = 0.99 / Val mAP@[.5:.95] = 0.945 (best epoch 13)
- Train loss 매끄럽게 단조 감소 (1.86 → 0.38)
- Detection 박스 IoU 평균 0.832 (75.6%가 IoU ≥ 0.8)
- 모델은 자기 학습 분포는 거의 완벽하게 해결합니다

**Test 29.8% 원인 = 학습 분포가 좁아서 일반화가 안 됨**
- Val 0.99 vs Test Top-1 0.298 → 70pp 갭
- Detection 95.7% (박스 단계는 일반화 성공)
- 분류 단계에서 학습 분포 밖 케이스를 못 풀어냄
- 모델이 시각 신호(색·형태)에만 의존해 처음 보는 환경/알약에서 작동 못 함

## 오탐 박스 정밀 분류

진단 단계에서는 16개 표본만 시각 검토 → 전체 패턴 단정에 한계 있었습니다. 304개 예측 박스 전수에 대해 IoU 매칭 후 정밀 분류를 진행했습니다.

### 매칭 분류 결과

| 카테고리 | 정의 | 개수 |
|---|---|---|
| TP | IoU ≥ 0.5 AND Top-1 = GT class | 14 (4.6%) |
| FP_A | IoU < 0.3 (localization 오탐) | 250 (82.2%) |
| FP_B | IoU ≥ 0.5 AND Top-1 ≠ GT class (classification 오탐) | 31 (10.2%) |
| GRAY | 0.3 ≤ IoU < 0.5 | 9 (3.0%) |

TP recall = 14/47 = 29.8% (Top-1 정답률과 동일).

### FP_A 250개 위치 분포

- 박스 중심이 이미지 가장자리 5% 이내: 110/250 (44.0%)
- 가장자리 10% 이내: 161/250 (64.4%)
- 좌측 가장자리 5% 이내 50개 vs 우측 18개: 좌측 2.78배 비대칭
- TP 14개는 모두 이미지 중앙 영역(cx 0.4~0.6, cy 0.4~0.6) 집중

### FP_A 패턴 분포

자동 분류 (위치/aspect 기준):

| 카테고리 | 개수 | 비율 | conf mean |
|---|---|---|---|
| edge_strip (가장자리 띠) | 79 | 31.6% | 0.077 |
| medium_ratio | 79 | 31.6% | 0.117 |
| normal_ratio | 63 | 25.2% | 0.154 |
| elongated_off_edge | 29 | 11.6% | 0.125 |

conf 상위 50 시각 검토 결과 발견 패턴: 손가락/손바닥 자체 박스(conf 0.2~0.34), 약 포장지 글자(예: "이알", "Pfizer", "Q25"), 나무 결, 천 주름, 알약 가장자리 부정확 잡기, 단색 배경 띠.

### conf threshold 영향

| threshold | FP_A 잔존 | 비율 |
|---|---|---|
| 0.05 (현재) | 250 | 100% |
| 0.1 | 78 | 31.2% |
| 0.2 | 35 | 14.0% |
| 0.3 | 14 | 5.6% |

threshold 0.1로 올리면 자동 1/3 감소 가능. 단 학습 개선 없이 threshold만 올리면 recall trade-off 측정 필요합니다.

## 각인 가시성 측정

진단 #3 (각인 학습 실패) 정량 근거 확보를 위해 합성 ROI 100개 + K-code 원본 100개에 대해 학습 입력 해상도(imgsz)별 각인 픽셀 보존율 측정.

각인 픽셀 정의: 알약 영역 안에서 Laplacian 절댓값이 상위 percentile(90) 이상인 픽셀. 측정 방법(M2): 원본을 imgsz 비율로 다운샘플 후 다시 원본 크기로 업샘플 → 같은 영역 lap 강도 비교.

### 학습 입력 단계 다운샘플 영향

cache ROI 평균 268×319. imgsz별 학습 입력 크기:
- imgsz=640 → 137×137 (절반 다운샘플)
- imgsz=1024 → 220×220 (cache 70% 보존)
- imgsz=1280 → 276×276 (거의 보존)

### imgsz별 각인 강도(lap) 보존율: 페어 비교

같은 ROI에서 imgsz 변경 시 보존율 차이:

| imgsz 변화 | 합성 ROI lap 변화 | K-code 원본 lap 변화 |
|---|---|---|
| 640 → 1024 | +3.4p | +14.1p |
| 1024 → 1280 | +34.5p | +44.7p |

합성 ROI와 K-code 원본 두 축 모두 1024→1280에서 의미 있는 점프 발생. 1024와 640 차이는 미미.

(합성 long side가 1280이라 합성 ROI 측정의 1280 = 원본 = 100%. 본 측정은 "현재 합성 환경에서 imgsz별 손실"이며 합성 자체를 더 크게 만들면 imgsz 1280에서도 손실 발생.)

### 누끼 처리 자체 손실

합성에 사용되는 cache는 rembg `isnet-general-use`로 누끼 처리된 ROI. K-code 원본 100 ROI 누끼 전/후 페어 측정:

| 지표 | 누끼 전 | 누끼 후 | 변화 |
|---|---|---|---|
| ratio_abs (%) | 11.50 | 8.29 | -3.22p |
| mean_lap | 33.52 | 27.91 | -5.61 |
| lap 보존율 | 100% | 83.53% | -16.47p |

→ 누끼 처리 자체로 각인 강도 평균 16.5% 손실. 합성 데이터의 각인 강도가 K-code 원본 대비 약 84% 수준에서 시작.

### 누끼 실패 케이스

100 ROI 중 7건이 합성 코드 alpha 임계 (>0.35)에 못 미쳐 합성 풀에서 제외됨. 6/7 건이 캡슐/PTP 형태, `isnet-general-use`가 캡슐류 누끼 실패율 높습니다. 합성 풀의 캡슐 비율이 원본 대비 낮을 가능성 (정확한 비율은 미측정).

## 측정 한계

1. 학습 입력 다운샘플 후 lap 보존율과 실제 모델 분류 성능의 직접적 인과 관계는 본 측정에서 검증 안 함 (재학습 후 평가로 확인 필요).
2. 합성 풀의 캡슐류 비율이 K-code 원본 대비 얼마나 낮은지 정량화 안 함.
3. K-code 원본 ROI 측정은 bbox crop RGB 전체 영역에서 lap 측정 (alpha 마스킹 부재). 알약 영역 외 픽셀이 lap 절대값에 일부 섞일 수 있으나, 다운샘플 보존율은 base가 같아 영향 없음.
4. 33장 테스트셋 기반 결과. 일반화 가능성은 측정 안 함.
