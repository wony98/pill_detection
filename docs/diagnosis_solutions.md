# 합성 데이터 개선 방향

진단 결과 = 모델이 학습 데이터의 시각 신호(색·형태)에 단축경로 학습. 처음 보는 환경/알약에서 작동 못 하는 일반화 문제. 합성 데이터를 다양성 + 각인 학습 강화 방향으로 다시 만드는 것이 목표입니다.

초점은 일반화 능력입니다. 사용자가 임의로 찍은 약 사진에서 작동하는 모델을 만듭니다.

## 개선 방향 우선순위

| 순위 | 방향 | 해결 문제 |
|---|---|---|
| 1 | 학습 입력 해상도 imgsz=1280으로 상향 | #3 각인 학습 실패 |
| 2 | 합성 알약 크기 분포 폭 확대 + 알약 개수별 분기 | #6 크기 다양성 부족 + 각인 가시성 |
| 3 | 합성 알약 개수 가중 샘플링 (1~5개 골고루) | #4 단일 알약 학습 부족 |
| 4 | 배경 풀 재구성 + 가장자리 처리 | #5 손가락 오탐 + 가장자리 비대칭 |

이전 진단에서 별개 항목으로 두었던 "클래스 균등 분포"는 코드 검토 결과 제외했습니다. `synthetic_images.py`에서 `random.choice(class_map.keys()) → random.choice(class_map[cls_idx])` 순서로 클래스 균등 샘플링이 이미 적용돼 있습니다. 핀 클래스 hallucination(#2)은 1+2번 방향이 각인 학습을 살리면 자연 해소될 가능성이 큽니다. 모델이 캡슐 형태 시각 신호에만 의존하지 않게 되기 때문입니다.

## 1. 학습 입력 해상도 imgsz=1280으로 상향

**현재**: `imgsz=640`

**문제**: 알약이 작게 합성된 상태에서 640으로 다운샘플되면 각인이 픽셀 단위로 소실됩니다. 모델이 각인을 학습 신호로 쓸 수 없게 되고, 결과적으로 색·형태 시각 신호에만 의존하는 단축경로 학습이 발생합니다. 핀 클래스 hallucination과 처음 보는 환경에서 작동 안 하는 일반화 부족의 직접 원인입니다.

**측정 근거**: 합성 ROI 100개 + K-code 원본 100개 두 축에 대해 imgsz별 각인 강도(lap) 보존율 페어 비교:

| imgsz 변화 | 합성 ROI lap 변화 | K-code 원본 lap 변화 |
|---|---|---|
| 640 → 1024 | +3.4p | +14.1p |
| 1024 → 1280 | +34.5p | +44.7p |

같은 ROI에서 imgsz 변경 시 lap 보존율 차이. 두 축 모두 1024와 640 차이는 미미, 1024→1280에서 의미 있는 점프가 발생했습니다. imgsz 1024로는 부족하고 1280까지 올리는 것이 효과적으로 보입니다.

**기대 효과**: 각인 정보 보존 → 모델이 색·형태 외에 각인까지 학습 신호로 사용 → 처음 보는 알약/환경에서도 작동하는 일반화.

**고려사항**: GPU 메모리/시간 증가. A100 메모리 한계 시 batch 16→8 조정이 필요할 수 있습니다. 합성 long side는 1280을 유지하되 더 키우는 방향(1600+)도 검토 여지가 있어 보입니다.

이 방향이 효과를 내려면 2번(알약을 충분히 크게 합성)과 함께 가야 합니다.

## 2. 합성 알약 크기 분포 폭 확대 + 알약 개수별 분기

현재 코드 (Step 3 generate 함수):
```python
if area_ratio > MAX_PILL_AREA_RATIO:  # 0.20
    scale = (MAX_PILL_AREA_RATIO / area_ratio) ** 0.5
    rgba = rgba.resize(...)
```
큰 crop만 다운스케일하고 작은 crop은 원본 그대로 통과 → 모든 알약이 좁은 크기 범위에 몰립니다. 또한 알약 개수와 무관하게 같은 임계값을 적용.

측정값 (정규화 면적 log10):

전체 분포 폭 (std):
| 데이터 | std | 평가 |
|---|---|---|
| 양질 1800 | 0.586 | 다양 |
| Test 33 | 0.355 | 중간 |
| 신규 5400 | 0.251 | 좁음 |
| K-code 학습 | 0.252 | 좁음 |

평균(mean)은 4축 모두 -1.23 근처로 거의 같습니다. 실제 차별점은 분포 폭(std)입니다.

알약 개수별 분포 (양질 1800):
| 알약 개수 | 비중 | mean | std | 의미 |
|---|---|---|---|---|
| 1개 | 21% | -0.68 | 0.131 | 클로즈업 (큰 ROI) |
| 2개 | 47% | -1.25 | 0.585 | 다양한 거리 |
| 3-4개 | 32% | -1.45 | 0.564 | 다양한 거리 |

신규 5400은 알약 개수와 무관하게 모든 그룹이 mean -1.22~-1.25 / std 0.25에 몰립니다. 양질이 자연스러운 이유 = 알약 개수에 따라 다른 크기 분포 적용 (1개 = 매우 크게 = 각인 보존, 다중 = 작고 다양 = 거리 다양성).

**개선 방향**:
- `MIN_PILL_AREA_RATIO` 신설로 양방향 스케일링 (작은 crop도 일정 크기 이상으로 업스케일)
- 알약 개수별로 다른 크기 임계값 적용 (1개일 때는 큰 ROI, 다중일 때는 다양한 거리)

**기대 효과**: 다양한 크기 학습 → 처음 보는 거리/각도에서도 작동. 단일 알약 케이스에 큰 ROI → 각인 픽셀이 선명해져 1번과 시너지.

## 3. 합성 알약 개수 가중 샘플링

**현재**: `MIN_PILLS=2, MAX_PILLS=4` → 합성 1개 비율 3.4% (양질 13.5%, 신규 0%)

**문제**: Test의 60.6%가 1개 알약인데, 모델은 1개 케이스 거의 학습 안 됨. 다중 알약 분포에 고정돼 처음 보는 단일 알약 시나리오에서 작동하지 못합니다.

측정값 (알약 개수 분포 비교):
| 데이터 | 1개 % | 2개 % | 3개 % | 4개 % | mean |
|---|---|---|---|---|---|
| K-code 학습 | 0 | 0 | 16.4 | 83.6 | 3.84 |
| 신규 합성 | 0 | 31.5 | 33.6 | 34.9 | 3.03 |
| 양질 합성 | 13.5 | 42.9 | 31.1 | 12.4 | 2.43 |
| Test | 60.6 | 36.4 | 3.0 | 0 | 1.42 |

**개선 방향**:
- `MIN_PILLS=1`로 낮춰 단일 알약 케이스 학습 자산 확보
- 1~5개까지 `random.choices` 형태의 가중 샘플링 적용
- Test가 1개 알약 위주이지만 학습이 1개에만 쏠리지 않도록 양질 분포와의 균형 고려

**기대 효과**: 알약 개수 어느 케이스든 작동하는 모델. Test 60.6%가 1개 케이스라 가장 큰 정답률 ↑ 효과 기대.

## 4. 배경 풀 재구성 + 가장자리 처리

**현재 문제 두 가지**:

### (1) 배경 풀 빈약 + 손가락 자산 부재

| 카테고리 | 배경 장수 | 한 배경당 재사용 |
|---|---|---|
| dark_surface | 42 | 24회 |
| fabric | 39 | 26회 |
| gray_surface | 51 | 20회 |
| marble_tile | 27 | 37회 |
| palm_hand | 6 | 167회 |
| white_paper | 24 | 42회 |

palm 배경 6장으로 합성 1000장 = 같은 손바닥 167회 반복. palm 6장 전수 시각 결과 모두 손금 매크로 클로즈업, 손가락 들어간 사진 0장. 7카테고리 모두 매크로 텍스처. 진단 #5 (palm 정답률 25%)의 직접 원인입니다.

환경별 색차 vs 정답률 분석에서 색차↑ → 정답률↑ 패턴이 명확하나, dark_surface / marble_tile 같은 색차 큰 환경에서도 정답률 낮음 (각인 자체가 안 보임). 1번 + 4번 조합이 답으로 보입니다.

### (2) 오탐 박스 가장자리 집중 + 좌측 비대칭

오탐 박스 250개 정밀 분석:
- 가장자리 10% 이내: 64.4% (161/250)
- 좌측 가장자리 5% 이내 50개 vs 우측 18개: 좌측 2.78배 비대칭
- TP 14개는 모두 이미지 중앙 영역(cx 0.4~0.6) 집중

학습 데이터가 알약을 이미지 중앙 + 격자 위주로 배치 → 가장자리에 알약이 거의 없음 → 모델이 가장자리 패턴(손가락 끝, 포장지 글자, 나무 결, 천 주름)을 알약으로 오인. conf 상위 50 시각 검토에서 모두 발견된 패턴입니다.

### 개선 방향

배경 풀:
- palm 배경 추가 수집 (특히 손가락이 들어간 사진)
- 한 배경의 재사용 횟수를 줄여 카테고리별로 다양화
- 색차 큰 환경(dark/marble)도 별도 풀로 보강

가장자리 처리:
- 합성 시 알약을 가장자리 가까이 배치하는 비율을 늘려 가장자리 학습 보강
- 학습 시 letterbox padding 적용 검토
- 손가락 영역을 별도 객체로 합성하되 알약 라벨링 X (네거티브 샘플)

**기대 효과**: 손가락/포장지 패턴 오탐 차단 + 가장자리 알약 학습 → 환경 무관하게 작동.

## 추가 검토할 만한 영역 (학습 외)

본 방향과 별개로 평가/post-processing 단계에서 빠르게 효과 확인이 가능한 영역도 있습니다:

### (1) conf threshold 0.05 → 0.1 검토

오탐 박스 자동 1/3 감소 가능 (FP_A 250 → 78). 단 학습 개선 없이 threshold만 올리면 recall 영향이 있을 수 있어 함께 측정이 필요합니다.

### (2) post-processing: 가장자리 5% 이내 박스 자동 필터

FP_A 110개 (44%) 자동 제거 가능. 단 알약이 실제로 가장자리에 있는 케이스는 false negative 리스크가 있어 알약 영역 비율 등 추가 조건 검토가 필요합니다.

## 신규 합성 5400장 처리 방향

신규 합성 5400장은 std 0.251로 다양성이 좁고 통합본 학습에서 정답률 하락에 기여한 것으로 보입니다. 폐기 대신 위 1~4번 방향을 적용해 같은 분량을 재생성하는 쪽이 학습 자산을 더 풍부하게 가져갈 수 있을 것 같습니다.

## 검증되지 않은 영역

본 시점에서 정량 측정이 안 된 영역:
1. 합성 풀의 캡슐류 비율이 K-code 원본 대비 얼마나 낮은지 (`isnet-general-use` 누끼 모델이 캡슐 실패율 7%)
2. 학습 입력 lap 보존율과 모델 분류 성능의 직접 인과 관계
3. 개선안 적용 후 마이너스 효과 가능성: 33장 정답률 ↑가 다른 영역 정답률 ↓로 이어질 가능성

위 영역들은 합성 데이터를 새로 만들어 재학습한 후 평가에서 확인 가능합니다.
