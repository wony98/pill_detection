# 3팀 EDA — 데이터 품질 및 모델링 이슈 리스트

**검토 대상**: 통합 CSV 기준 Kaggle + AI Hub  
**데이터 규모**: 40,844 annotation / 10,697 이미지 / 118 클래스

**상태 표기**
- ✅ **확증**: 실측/시각화로 문제 또는 특성이 확인됨
- ⚪ **정보성**: 결함은 아니지만 모델링 시 유의가 필요한 사항
- ❌ **기각**: 의심했으나 실측 결과 문제 없음

---

## 이슈 목록

### [A] bbox 경계 초과 ✅ 확증
- **정의**: bbox가 이미지 범위를 벗어나는 경우
- **실측**: 1 annotation
- **해석**: 명백한 어노테이션 오류로 공통 제거 대상입니다.

### [B] bbox 중심 좌표 이상치 ✅ 확증
- **정의**: bbox 중심 좌표가 이미지 범위를 벗어나는 경우
- **실측**: 1 annotation
- **해석**: 경계 초과와 동일 계열의 좌표 오류로 볼 수 있습니다.

### [C] 동일 bbox 좌표 중복 ✅ 확증
- **정의**: 같은 이미지 내에서 동일 bbox 좌표가 반복되는 경우
- **실측**: 142 annotation
- **해석**: 완전 동일 좌표 중복은 점검 및 정제 대상입니다. 다만 중복 후보 전체를 즉시 오류로 단정하기보다는, 실제 좌표 단위 재검토 후 처리 여부를 결정하는 것이 적절합니다.

### [D] 위치 편향 ⚪ 정보성
- **정의**: bbox 중심 좌표가 특정 위치 군집에 집중되는 현상
- **실측**: 4개 슬롯형 군집 경향 확인
- **해석**: 조합 이미지 구조상 알약이 몇 개의 정해진 위치에 반복 배치되는 경향이 있으며, 모델이 위치 정보에 과도하게 의존할 위험이 있습니다.

### [E] 색상+형태 중복도 높음 ⚪ 정보성
- **정의**: 동일 색상+형태 조합에 여러 클래스가 집중되는 현상
- **실측**: 하양+원형 20개 클래스, 하양+장방형 18개 클래스
- **해석**: 단순 외형 정보만으로는 구분이 어려운 클래스가 많습니다.

### [F] 시각적 유사 클래스 다수 존재 ⚪ 정보성
- **정의**: 색상, 형태, 평균 크기, 종횡비가 동시에 유사한 클래스 쌍이 많은 현상
- **실측**: 유사도 3.5 이상 239쌍, 3.0 이상 462쌍
- **해석**: 실제 이미지 비교에서도 혼동 가능성이 높게 나타났으며, 각인 문자와 세부 윤곽 차이가 핵심 구분 요소가 될 가능성이 큽니다.

### [G] 희귀 클래스 부재 ❌ 기각
- **정의**: 10개 이하 샘플을 가진 극단적 희귀 클래스 존재 여부
- **실측**: 10개 이하 희귀 클래스 0개
- **해석**: 극단적인 희소 클래스 문제는 확인되지 않았습니다. 다만 클래스 간 샘플 수 차이는 존재하므로 중간 수준의 불균형은 남아 있습니다.

### [H] 객체 크기 편차 큼 ⚪ 정보성
- **정의**: 한 이미지 안에서 작은 객체와 큰 객체가 동시에 존재하는 현상
- **실측**: 최대/최소 면적 비율 중앙값 3.10, 상위 사례 40배 이상도 존재
- **해석**: 한 이미지 안에서도 객체별 탐지 난이도가 균일하지 않으며, 소형 객체 성능 확보가 별도 과제가 될 수 있습니다.

### [I] 종횡비 분포 비대칭 ⚪ 정보성
- **정의**: 객체 종횡비가 정방형에만 모이지 않고 세로형, 가로형까지 분산되는 구조
- **실측**: 정방형 53.0%, 세로형 35.1%, 가로형 11.9%
- **해석**: 객체 비율이 일정하지 않아 입력 크기와 탐지 설정에 영향을 줄 수 있습니다.

### [J] 각도 변화 영향은 제한적 ❌ 기각
- **정의**: 70도/75도/90도 변화가 bbox를 크게 흔들 수 있다는 의심
- **실측**: 면적 변화율 중앙값 8.91%, 10% 이하 59.8%, 30% 초과 1.0%
- **해석**: 정상 샘플 기준 각도 변화 영향은 크지 않은 편입니다. 극단값은 실제 각도 변화보다 이상 bbox 영향일 가능성이 높습니다.

### [K] 실제 크기와 bbox의 부분적 연관 ⚪ 정보성
- **정의**: 실제 약 크기와 이미지상 bbox 크기가 어느 정도 연결되는지 여부
- **실측**: leng_long vs bbox_w 상관계수 0.6678, leng_short vs bbox_h 상관계수 0.2574
- **해석**: 긴 축 방향은 어느 정도 연관성이 있으나, 짧은 축 방향은 일관성이 약합니다. 실제 크기 정보는 보조 지표로 활용하는 것이 적절합니다.

### [L] 각인 정보 강한 식별 단서 ⚪ 정보성
- **정의**: 각인 정보가 실제 분류에 의미 있는 단서로 작동하는지 여부
- **실측**: 앞면 각인 있음 97.15%, 뒷면 각인 있음 41.98%, 완전 무각인 클래스 2개
- **해석**: 실제 crop에서도 각인이 육안상 식별 가능한 경우가 많아, OCR 또는 문자 기반 후처리 확장 가능성이 높습니다.

### [M] 색상/형태 라벨 타당성 양호 ⚪ 정보성
- **정의**: `color_class1`, `drug_shape` 메타데이터가 실제 이미지와 대체로 일치하는지 여부
- **실측**: 대표 샘플 직접 확인 결과 전반적으로 타당
- **해석**: 형태 라벨은 비교적 안정적이며, 색상 라벨은 조명과 반사 영향으로 다소 애매해질 수 있습니다.

### [N] 소형 객체 난도 존재 ⚪ 정보성
- **정의**: 작은 알약이 실제 원본 이미지에서 탐지하기 어렵게 보이는지 여부
- **실측**: 최소 면적 객체는 전체 화면 기준 매우 작게 보이는 사례 다수
- **해석**: 큰 객체 옆에서 상대적으로 덜 눈에 띄는 소형 객체가 존재하여 소형 객체 탐지 난도가 실제로 확인됩니다.

### [O] 저품질 이미지 일부 존재 ⚪ 정보성
- **정의**: 저밝기, 저대비, 저선명도 이미지가 존재하는지 여부
- **실측**: 평균 밝기 127.41, 평균 대비 20.98, 평균 선명도 37.32 / 하위 품질 샘플 일부 확인
- **해석**: 전반적 품질은 양호하지만 일부 저품질 이미지가 존재합니다. 다만 전면 제거보다는 선택적 보정 또는 augmentation 보완이 더 적절해 보입니다.

### [P] 선명도 절대 임계값 100 부적합 ❌ 기각
- **정의**: 선명도 100 이하 이미지를 저품질로 일괄 판단할 수 있는지 여부
- **실측**: 10,697장 전부 100 이하
- **해석**: 현재 데이터 분포 대비 임계값이 지나치게 높아 절대 기준으로는 부적절합니다. 상대 비교 지표로만 활용하는 것이 타당합니다.

### [Q] 배경 난이도 낮음 ⚪ 정보성
- **정의**: 배경이 복잡하여 탐지 난도를 높이는 구조인지 여부
- **실측**: 대부분 단순한 단색 계열 평면 배경
- **해석**: 현재 데이터셋은 복잡한 배경 분리보다는 객체 자체 구분에 더 집중할 수 있는 구조입니다.

### [R] 촬영 환경 통제 / 도메인 갭 가능성 ⚪ 정보성
- **정의**: 촬영 환경이 일정하게 통제되어 실제 환경과 차이가 생길 가능성
- **실측**: 배경, 조명, 구도가 전반적으로 유사하며 일부 반사광·비네팅 존재
- **해석**: 현재 데이터셋 내부 일관성은 높지만, 실제 환경 일반화 시 도메인 갭이 발생할 가능성이 있습니다.

### [S] 조합 이미지 반복 패턴 존재 ⚪ 정보성
- **정의**: 이미지당 알약 수와 조합 패턴이 무작위가 아니라 반복되는 구조
- **실측**: 4개 조합 81.78%, 3개 조합 17.77%, 평균 3.82개
- **해석**: 완전 무작위 조합 데이터가 아니라 일정한 반복 패턴을 가진 조합형 데이터셋으로 볼 수 있습니다.

### [T] 클래스 불균형은 중간 수준 ⚪ 정보성
- **정의**: 클래스별 샘플 수 차이가 존재하는지 여부
- **실측**: 극단적 희귀 클래스는 없으나 최다/최소 클래스 간 차이 존재
- **해석**: 극단적 불균형은 아니지만, 클래스별 성능 차이는 발생할 수 있는 구조입니다.

### [U] 제형 편중 존재 ⚪ 정보성
- **정의**: 특정 제형 중심으로 데이터가 구성되는 현상
- **실측**: 필름코팅정 비중이 가장 높고, 나정 및 경질캡슐제·산제가 뒤를 이음
- **해석**: 시각적 다양성은 존재하지만 특정 제형 중심 편중이 있으므로, 제형별 특성이 모델에 반영될 가능성이 있습니다.

### [V] 약효군 다양성 확보 ⚪ 정보성
- **정의**: 약효군 범위가 좁지 않고 다양한지 여부
- **실측**: di_class_no 기준 18개 약효군
- **해석**: 향후 헬스케어 확장 시 약효군, 제형, 각인, 색상, 형태를 함께 활용하는 다중 메타데이터 전략이 가능해 보입니다.

## 검토 방법론

1. 통합 CSV 기준으로 클래스, bbox, 메타데이터 분포를 정량 분석하였습니다.  
2. bbox 이상치, 중복 bbox, 이미지 품질 하위 샘플을 별도로 추출하여 점검하였습니다.  
3. 혼동 후보 클래스 쌍, 각인, 색상/형태, 소형 객체, 배경/조명 조건은 실제 이미지 crop 및 원본 이미지 시각화를 통해 육안 확인하였습니다.  
4. 즉, **수치 기반 탐지 + 시각 기반 검증**을 함께 사용하여 결론을 정리하였습니다.

## 모델링 시 우선 고려 사항

1. **bbox 좌표 이상치 제거 및 완전 중복 bbox 점검**  
2. **위치 편향과 조합 슬롯 구조를 고려한 해석**  
3. **소형 객체 성능 확보를 위한 입력 크기 및 설정 검토**  
4. **각인 정보 활용 가능성 검토**  
5. **저품질 이미지에 대한 선택적 보정 또는 augmentation 보완**  
6. **배경·조명 도메인 갭을 완화할 일반화 전략 검토**
