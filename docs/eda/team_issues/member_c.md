## 이슈 목록

### [A] bbox 경계 초과 ✅ 확증
- bbox 좌표가 이미지 범위(976x1280)를 벗어나는 경우
- 실측 1건, 해당 이미지 제거

### [B] bbox 크기 미달 ✅ 확증
- bbox 가로 또는 세로가 50px 미만이거나 이미지 면적 대비 비율 0.01 미만
- 시각화로 어노테이션 오류 확인
- 실측 15건, 해당 이미지 제거

### [C] 완전 중복 bbox ✅ 확증
- 같은 이미지 내 동일 좌표에 서로 다른 클래스 2개 할당된 어노테이션 오류
- 실측 142 annotation / 71 이미지, 해당 이미지 제거

### [D] 이미지당 알약 수 초과 ✅ 확증
- 이미지당 알약 수가 프로젝트 목표(최대 4개) 초과
- 테스트셋 확인 결과 5개 이상 이미지 없음 확인
- 실측 17 이미지, 해당 이미지 제거

### [E] area 결측 ✅ 확증
- bbox 면적 정보 결측값
- 실측 2건, 해당 이미지 제거

### [F] 라벨 누락 ✅ 확증
- 파일명 알약 코드 vs 실제 어노테이션 category_id 불일치
- mapping 테이블 기반으로 정확한 탐지 (단순 -1 오프셋 방식 대신)
- 실측 230 이미지, 해당 이미지 제거

### [G] 카메라 각도 누락 ⚪ 정보성
- 동일 알약 조합에서 70/75/90도 중 누락된 각도 존재
- 실측 77개 조합
- 제거하지 않고 학습 시 회전 증강으로 보완 예정

### [H] 클래스 불균형 ⚪ 정보성
- 클래스별 어노테이션 수 차이 존재
- 최다 878개 / 최소 71개 / 평균 326개
- 극단적 불균형은 아니나 100개 미만 클래스 6개 존재
- 학습 시 class_weights로 처리 예정
