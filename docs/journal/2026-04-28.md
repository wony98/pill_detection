## [5] 오늘 분석/실험 중 얻은 인사이트나 발견한 문제점

오늘 정리된 점입니다.

- mmcv의 공식 wheel(설치용 미리 빌드된 패키지)은 PyTorch 2.1까지만 매칭됩니다. 코랩의 최신 런타임(2026.04 기준 Python 3.12 + PyTorch 2.10)에서는 mmdet 호환이 안 되어, 이전 버전 런타임(2025.07)으로 다운그레이드해야 합니다.
- 구글 드라이브 마운트 timeout 시에는 캐글 데이터셋 우회가 훨씬 빠릅니다(17.5GB 47초). 대용량 데이터셋 운영 패턴 자체를 드라이브에서 캐글 데이터셋으로 옮길 만한 차이입니다.
- pycocotools는 `dataset['info']` / `licenses` 키를 deepcopy 시점에 강제로 요구합니다. YOLO → COCO 변환기에서 빈 키라도 박아 두지 않으면 평가 단계에서 `KeyError`로 죽어 버립니다.
