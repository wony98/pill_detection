# 모델 비교 분석: 후보 3개 깊이 비교

`docs/model_selection/selection_criteria_v3.7.md`의 4~5단계(seed=100 재학습 + 1위 결정 + 깊이 비교)에 해당하는 분석 결과입니다. 분석 노트북은 `eval/model_comparison.ipynb`입니다.

3팀에서 각자 학습한 8개 모델 중, 1~2단계 임계값(Top-3 ≥ 27.7%)을 통과한 상위 3개 후보(RTMDet-tiny, RT-DETR, YOLOv8s)를 대상으로 4단계 재현성 검증과 5단계 깊이 비교를 수행했습니다.

---

## 4단계: seed=42 + seed=100 평균 (재현성 검증)

후보 3개를 seed=100으로 재학습하여 셀프체크 v3.1을 통과한 seed만 평균에 반영했습니다.

| 모델 | seed=42 Detection | seed=100 Detection | 평균 Top-1 | 평균 Top-3 | params (M) |
|---|---|---|---|---|---|
| RTMDet-tiny | 97.9% (통과) | 95.7% (통과) | 31.9% | 42.6% | 4.91 |
| RT-DETR | 91.5% (통과) | 85.1% (통과) | 24.5% | 33.0% | 33.00 |
| YOLOv8s | 83.0% (통과) | 93.6% (통과) | 17.0% | 24.5% | 11.18 |

세 모델 모두 두 seed에서 셀프체크 v3.1을 통과했습니다. 평균 산출 기준은 두 seed 평균입니다.

---

## 5단계 (a): 1위 결정

1위(RTMDet-tiny Top-1 31.9%)와 3위(YOLOv8s Top-1 17.0%) 간 점수차는 14.9%p로, 임계값 5%p를 초과하여 격차 큼 분기로 진입했습니다.

### 신뢰성 검증 3중 (RTMDet-tiny)

격차 큼 분기에서는 1위 후보의 신뢰성을 3중으로 검증합니다.

| 검증 | 측정 | 결과 |
|---|---|---|
| ① 정답 분포 (mode collapse 체크) | 정답 16개가 14개 알약에 분포, 최빈 알약 빈도 2회 | 쏠림 없음 (통과) |
| ② 오답 패턴 (의미 있는 혼동인지) | 의미있음 28/30, 무작위 1/30, 미분류 1/30 | 의미 있는 혼동 우세 (시각 특성 학습 증거, 통과) |
| ③ 학습 데이터 누수 | 평가셋 ∩ train 0장, 평가셋 ∩ val 0장 | 누수 없음 (통과) |

3중 검증 모두 통과 → RTMDet-tiny 1위 확정.

## 5단계 (b): 깊이 비교 분석

후보 3개의 약점·강점을 케이스 묶음과 오답 패턴 두 축으로 비교했습니다. 33장 평가는 small sample이라 % 표시가 오해를 유발할 수 있어 절대 개수만 표기합니다.

| 분홍 원형 | 1 | 0 | 0 | 0 |
| 분홍 장방형 | 2 | 0 | 0 | 0 |

| 주황 원형 | 5 | 2 | 0 | 0 |

**관찰**:
- 가장 큰 묶음인 하양 장방형(n=14)에서 RTMDet-tiny가 6개로 우위 (YOLOv8s 2개, RT-DETR 3개).
- 갈색 타원형(n=6)에서도 RTMDet 3개 vs YOLOv8s 0개로 차이가 큽니다.
- 주황 원형(n=5)은 RTMDet 2개 / YOLOv8s 0개 / RT-DETR 0개로 다른 모델은 전혀 잡지 못한 구간입니다.

### 오답 패턴 분류

오답 케이스를 "의미있음 / 무작위 / 미분류" 세 유형으로 분류했습니다. "의미있음"은 같은 색상·형태군 내 혼동(시각 특성 학습 흔적), "미분류"는 사람 판정 보류, "무작위"는 시각 특성과 무관한 혼동입니다.

| 모델 | 의미있음 | 무작위 | 미분류 | 합계 |
|---|---|---|---|---|
| RTMDet-tiny | 28 | 1 | 1 | 30 |
| YOLOv8s | 8 | 0 | 21 | 29 |
| RT-DETR | 8 | 0 | 25 | 33 |

RTMDet-tiny는 오답 대부분(28/30)이 시각 특성 기반 의미 있는 혼동인 반면, YOLOv8s와 RT-DETR은 미분류 비중이 70~75%로 높습니다. RTMDet-tiny는 시각 신호(색상·형태·각인)를 학습 단서로 쓴 반면, 다른 두 모델은 무작위 추정에 가까운 패턴으로 보입니다.

## 결론: RTMDet-tiny 채택

| 근거 | 결과 |
|---|---|
| 1위 결정 | Top-1 31.9% (2위 대비 +7.4pp, 3위 대비 +14.9pp) |
| 신뢰성 검증 3중 | 정답 분포 / 오답 패턴 / 학습 누수 모두 통과 |
| 케이스 묶음 강점 | 가장 큰 묶음(하양 장방형 n=14)에서 우위 + 다른 모델이 못 잡은 구간(주황 원형) 잡음 |
| 오답 품질 | 의미 있는 혼동 28/30 (다른 모델은 8/29~33으로 미분류가 대부분) |
| 모델 사이즈 | 4.91M (RT-DETR 33M 대비 1/7, YOLOv8s 11.18M 대비 1/2 미만) |

RTMDet-tiny가 1위 확정되어 6단계 배포 적합성 검증으로 진입했습니다 (CPU 1.03초/장 측정, `docs/v4_summary.md` 참조).
