오늘 정리된 점입니다.

- 캐글 자료와 AI Hub 자료는 같은 원천(AI Hub 공개 데이터)에서 출발한 자료로 보입니다. 이미지 메타 JSON 스키마(50개 필드)가 두 출처에서 완전히 일치하고, 양쪽에 공통으로 존재하는 약품 54종의 약품명 필드(`dl_name`)도 100% 일치합니다. 캐글 쪽은 AI Hub 데이터의 일부를 재포맷한 형태로 이해할 수 있습니다.

발견한 문제는 다음 세 가지입니다.

- AI Hub 원본 자료에서 손상 1건을 발견했습니다. `K-016551-오류`라는 폴더명에 한글이 섞여 있고, 해당 폴더 안의 JSON은 line 59 column 12에서 파싱이 실패합니다.

- bbox 형식 오류가 155건 잡혔습니다. 빈 배열(`[]`)이거나 숫자가 잘못 병합된 케이스로, 원본 라벨링 품질 이슈로 보입니다.
