- K-code 기준 검증 셋의 천장 효과(99%)는 진단 도구로는 부적합합니다. 도메인 차이 격차를 보여 주는 용도로만 한정해서 쓰는 편이 맞습니다.

- albumentations 2.0+에서 API가 바뀌었습니다. `GaussNoise(var_limit=...)`는 폐기되었고 `std_range`로 바뀌었습니다. 1.x 코드는 조용히 무시되며 `UserWarning`만 뜨기 때문에, dry run 검증이 필수입니다.
