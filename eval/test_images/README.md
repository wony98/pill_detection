# eval/test_images/

평가용 테스트 이미지 33장. 정답 파일은 [`eval/test_labels/`](../test_labels/)에 동일한 파일명(.txt)으로 매칭.

- **총 장수**: 33
- **이미지 형식**: PNG (다양한 해상도, 다양한 배경, palm/desk/cloth/paper/bottle/box)
- **명명 규칙**: `<제품명>[_용량].png` (예: `게보린정 300mg_3.png`)

평가 관련 노트북: [`eval/compare_experiments.ipynb`](../compare_experiments.ipynb), [`eval/cpu_inference_RTMDet_seed100.ipynb`](../cpu_inference_RTMDet_seed100.ipynb).
