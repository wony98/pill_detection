# ppt_figures/

PPT 발표 자료(`docs/healtheat_presentation.pptx`)에 들어간 슬라이드용 그림 모음.

파일명 앞쪽 숫자는 슬라이드 번호 매핑 단서 (예: `04_*` = 슬라이드 4, `05_*` = 슬라이드 5).

## 구성

| 그룹 | 내용 |
|---|---|
| `04_*` | 데이터 이슈 — class long-tail, P/Q/R 이슈 |
| `05_*` | 배경 다양성 — palm/dark surface 샘플, rembg, 합성 v2/v3 |
| `06_*` | augmentation ablation 결과 |
| `07_*` | YOLOv8n 베이스라인 진단 (F1/PR/confusion/IoU) |
| `10_*` | 학습 커브, IoU 분포 |
| `11_*` | 환경별/클래스별 정답률 |
| `12_*` | confidence 분포, FP heatmap |
| `13_*` | Top-3 recovery |
| `14_*` | confusion pairs, imprint 가설, pin 클래스 |
| `17_*` | 33장 평가셋 그리드 |

> 분석 단계에서 만든 raw 그림은 `analysis/figures/`, EDA 단계 그림은 `eda/figures/` 참조.
