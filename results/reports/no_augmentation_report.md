# No Augmentation 실험 보고서

## 실험 목적

본 프로젝트의 baseline은 "ultralytics 기본 증강 세트"로 정의되어 있으나, 기본 증강 자체가 이미 여러 기법(mosaic, fliplr, hsv, scale 등)을 포함하고 있어 "순수 baseline" 기준점이 부재했음. 본 실험으로 증강 없는 상태의 모델 성능을 검증함.

## IoU Threshold별 성능 분석

모델의 bbox 정확도를 다각도로 검증하기 위해 IoU threshold를 0.5부터 0.95까지 10개 지점에서 mAP 측정.

### IoU별 mAP 수치

| IoU | mAP | 전 구간 대비 변화 |
|---|---|---|
| 0.50 | 0.9867 | — |
| 0.55 | 0.9864 | -0.0003 |
| 0.60 | 0.9853 | -0.0011 |
| 0.65 | 0.9853 | 0.0000 |
| 0.70 | 0.9849 | -0.0004 |
| 0.75 | 0.9844 | -0.0005 |
| 0.80 | 0.9838 | -0.0006 |
| 0.85 | 0.9819 | -0.0019 |
| 0.90 | 0.9777 | -0.0042 |
| 0.95 | 0.9359 | -0.0418 |

### 관찰

- IoU 0.5~0.9 구간에서는 mAP가 0.98 선에서 거의 평탄하게 유지됨
- IoU 0.95에서 급격한 하락(-4%) 발생
- 모델이 매우 정확한 bbox를 생성하고 있으나, 픽셀 단위 극한 정확도에서는 한계 존재

### Kaggle 평가 지표 (mAP@[0.75:0.95]) 추정

Kaggle 공식 평가는 IoU 0.75~0.95 구간 평균을 사용.
- 해당 구간 평균 mAP: 약 0.9727 (0.9844 + 0.9838 + 0.9819 + 0.9777 + 0.9359) / 5
- 전체 구간 평균(mAP@0.5:0.95 = 0.9792)보다 낮음. IoU 0.95 구간이 평균을 끌어내림

## 주요 관찰

### 1. 증강 없이도 val mAP@0.5 0.98 이상 달성

증강을 전부 제거한 상태에서도 모델이 val 데이터에 거의 완벽히 수렴. 데이터 자체의 난이도가 낮거나 train/val 분포가 유사하다는 뜻.

### 2. Train-Val Loss 갭 관찰

Train box_loss는 epoch 30까지 지속 하락(0.441 → 0.084), 반면 val box_loss는 epoch 5에서 수렴 후 정체(0.186 부근). 일반적 의미의 과적합이 발생했으나, val 성능은 하락하지 않음.

### 3. 조기 수렴

Epoch 5에서 이미 mAP@0.5 0.9868 달성. 이후 25 epoch 추가 학습의 효과 미미. 향후 실험에서 epoch 수를 줄여 학습 시간 단축 가능.

### 4. Bbox 정확도 우수

IoU 0.5~0.9 구간에서 성능이 거의 평탄하게 유지됨. 이는 모델이 느슨한 기준뿐 아니라 엄격한 기준에서도 일관된 성능을 보임을 의미. 단, IoU 0.95 구간에서는 뚜렷한 하락이 있어 개선 여지 존재.
